# HTML5 Fundamental Tasks & Core Concepts

This repository contains basic to intermediate HTML5 practice tasks ceated during Bsc IT Semester 3. It demonstrates essential web development concepts, semantic structure, forms, and table layouts.

---

## 1. Student Registration Form (`form.html`)
* **Real-World Use:**User sign-up/login pages, feedback forms, survey questionnaires, and online admissions.
* **Key HTML Tags & Attributes USed:**
   * `<form>`: Main container used to capture and process user input.
   * `<input>`: Captures various data types (`type="text"`, `email`, `password`).
   * `type="radio"`: Allows selection of a single option from a group (e.g., Gender).
   * `type="checkbox"` : Allows selection of multiple options simultaneously (e.g., Hobbies).
   * `<select>` & `<option>` : Creates a drop-down list for concise selection options.
   * `<textarea>`: Provides a multi-line input box for address or bio descriptions.
   * `required`: Ensures mandatory form field validation before submission.

   ---

   ## 2. College Timetable (`timetable.html`)
* **Real-World Use:** Displaying structured grid data such as event schedules, pricing plans, and timetables.
* **Key HTML Tags & Attributes Used:**
  * `<table>`, `<thead>`, `<tbody>`: Organizes data cleanly into rows and columns.
  * `<th>` & `<td>`: Represents header cells (bold/centered) and standard data cells.
  * `rowspan`: Merges cells vertically across multiple rows (e.g., Lunch break).
  * `colspan`: Merges cells horizontally across multiple columns (e.g., Lab Session block).

---

## 3. Portfolio Preview Card (`portfolio_demo.html`)
* **Real-World Use:** Building clean, accessible, and SEO-friendly personal portfolio websites using semantic HTML5.
* **Key HTML Tags & Attributes Used:**
  * `<header>`: Contains top-level branding, titles, and site introduction.
  * `<main>`: Holds the primary central content of the webpage.
  * `<section>` & `<article>`: Groups related content logically into reusable blocks.
  * `<a>`: Hyperlinks external web pages or repositories (`target="_blank"` opens links in a new browser tab).
  * `<footer>`: Contains copyright information, author credits, and contact links.
